# Native named poses and command parity

Implementation base: `956047d`. Scope follows [the ecosystem guide](neoforge-ecosystem-replacements-2026-09-22.md).

## Command behavior

`/npc pose --save name` now stores the selected NPC's current/stored yaw and pitch, matching the original Citizens command. The earlier native implementation saved the command sender's angles; that behavior belongs to `--mirror name` and is now available under that option. Saving an unspawned NPC uses its stored direction without spawning it or changing its stored spawn location.

| Operation | Result |
|---|---|
| `--save name` | Save the NPC's yaw and pitch. Optional `--yaw` and/or `--pitch` override only the supplied angle. |
| `--mirror name` | Save the command source's yaw and pitch. Existing `--location` / `--entitylocation` source overrides remain supported. |
| `-d` with save or mirror | Make the new named pose the default. |
| `--assume name` | Submit the stored direction to the existing native RotationTrait session. Spawn at the stored position if necessary and available. |
| `--default name` | Select an existing usable pose as the idle default. |
| `--remove name` | Remove a named pose, including a retained invalid record with that name. |
| `-a` | Assume the command source's direction. It also runs after a supplied save/mirror/default/assume/remove operation, as in the original command. |
| No operation, optionally a page | List stable insertion-order IDs, names and pitch/yaw values. Listing does not attach a trait. |

Only one primary operation is accepted. `-d` requires save/mirror; explicit yaw/pitch requires save. These invalid combinations, unknown flags, invalid pages, missing poses, duplicate names, nonfinite angles and invalid names are rejected before collection changes or unnecessary trait attachment. A trailing `-a` resolves its source before a preceding mutation. This prevents a failed source lookup from leaving a partially applied save/remove/default operation.

Native command sources have position and rotation even when they are not players. Mirror and `-a` consume that native context, including a positioned/rotated command source, rather than imposing Bukkit's sender-location rules. Source location overrides are resolved through the existing native command-location parser. No new world-resolution fallback is introduced.

## Persistence and API behavior

The existing `list.<index>: name;pitch;yaw` format and `defaultPose` field remain in use. New pose names must be nonblank and cannot contain the format's semicolon delimiter. Added and assumed directions must be finite. Name lookup and default selection use `Locale.ROOT` instead of the host's default locale. Returned pose maps remain detached snapshots and now preserve insertion order for consistent listing and serialization.

Malformed saved strings and nonfinite saved angles are reported and retained as inactive raw records. They cannot submit native rotations or act as usable defaults. Saving and reloading retains those strings rather than dropping them. Explicitly adding a valid pose with the same name replaces its invalid record; explicit removal deletes the matching retained record. Other retained records survive that repair. Valid entries retain the original pitch/yaw order.

Assuming a pose still uses RotationTrait's normal interpolation and the existing idle/default arbitration. Defaults yield while navigating and return when idle. An NPC with no stored position is not spawned at an invented position. LookClose arbitration is unchanged.
