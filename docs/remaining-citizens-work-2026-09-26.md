# Remaining Citizens work

This is the current command and acceptance checklist for Minecraft 1.21.1. The September 13 audit contains historical gaps; later follow-ups supersede those rows. See the [ecosystem scope](neoforge-ecosystem-replacements-2026-09-22.md) for provider ownership.

All 37 historically missing 1.21.1 `/npc` command names have entry points. Entry-point coverage is not behavior parity, and the historical missing-command count must not be used as today's backlog or a completion percentage.

A read-only declaration scan of the checked-in `main` and `neoforge` source trees on 2026-09-27 10:55:42 +08:00 (UTC+08:00) found eight unmatched pairs: `npc chicken`, `npc cow`, `npc pig`, `npc coppergolem`, `npc mannequin`, `npc sulfurcube`, `waypoints hpa` and `wp hpa`. The first six concern newer-version entity capabilities. The two HPA debugging aliases are now implemented and validated in the [native HPA follow-up](hpa-debugging-2026-10-03.md). Historical inventory evidence: `artifacts/command-inventory-2026-09-27.json`. The declaration scan does not validate parameter handling or runtime behavior.

## Command coverage

The known ordinary Minecraft 1.21.1 command groups and HPA debugging aliases on this checklist now have implementation follow-ups. HPA constructs an actual hierarchical portal graph against a loaded-chunk snapshot, searches it in the background and prints the refined path. It preserves existing navigation and waypoint state. This does not establish every command/provider/client combination or complete the broader Citizens goal.

Recent follow-ups cover [`powered`, `name` and `home` options](command-options-home-2026-09-28.md), [`armorstand` limb poses](armorstand-poses-2026-09-27.md), `follow`, `mount`, `pose`, `lookclose` / `look`, native command locations, removal targeting, text editing, entity/display commands and particle options. The command-options fixture passes 164 checks, including atomic validation, original duration/precedence, native powered admission and exact home navigation ownership. `horse --color` and `--colour` both exist; upstream's unused `minecart --item` parameter is not a missing implemented behavior.

## Behavior, data and integration acceptance

- [NPC save integrity](npc-save-integrity-2026-10-04.md) now rejects trait/delegate serialization failures before publishing native snapshots or store batches, retains removal intent across retries/destinations, preserves namespaced document paths and rejects obsolete registry snapshots. Both NeoForge versions pass 98 dedicated checks each, including registered save commands and store-switch failures. All related regressions, 274 ordinary tests, 100 Interactions tests and clean build/archive checks pass. Atomic/ordered YAML writes, persistence delegate initialization failures and large-store snapshot costs retain targeted work.

- [Default-store replacement](npc-store-replacement-2026-10-03.md) now binds loading, allocation, deletion and saving to the replacement, honors startup overrides and retires old runtime ownership. Both NeoForge versions pass runtime/early/late phases, 480 checks total. Reported load/save failures preserve the previous binding; synchronous YAML write errors propagate, and saved redirects retain/recover their targets. Native serialization failures are covered by the save-integrity follow-up above. Configuration/shop reload and ordinary/named-registry reload/shutdown lifecycles retain targeted work.

- [NPC identity allocation and failed reloads](npc-data-restoration-2026-10-03.md) reserve IDs for unloaded definitions, isolate rejected records and preserve live NPCs when the source cannot be read. Native provider absence/presence/absence cycles pass on both NeoForge versions. Custom provider/trait and external backend contracts still need appropriate acceptance.

- [Native HPA debugging](hpa-debugging-2026-10-03.md) passes 109 command/snapshot checks on each NeoForge version and 16 algorithm tests. Height bounds, hierarchical refinement, blocked corners, repeated queries, dirty rebuilds, request ownership and cancellation are covered. The diagnostic remains bounded to its captured regions and the original land-walking model; it does not add a selectable NPC navigator. Interactions remains an independent mod/JAR with unchanged entry contents.

- [Waypoint lifecycle and delayed actions](waypoint-lifecycle-2026-10-03.md) repair unknown-provider route loss, old behavior cleanup, unavailable/disabled data retention, nested snapshot isolation, delayed-trigger and pause ownership, and request-specific navigation callbacks.
