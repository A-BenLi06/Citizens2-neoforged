# Independent Interactions NeoForge JAR

Verified against implementation base `1f8c3e5` on 2026-10-04 20:59:22 +08:00 (UTC+08:00).

Citizens and Interactions share this repository and Gradle project but ship as separate NeoForge mods. Dependency is Interactions → Citizens. Citizens has no reverse dependency or references to the Interactions engine.

| Mod | Source set | Binary artifact |
|---|---|---|
| Citizens, mod ID `citizens` | `neoforge/src/main` | `citizens-2.0.43-neoforge-SNAPSHOT.jar` |
| Yuuniverse Interactions, mod ID `interactions` | `neoforge/src/dialogue` | `yuuniverse-interactions-2.0.43-neoforge-SNAPSHOT.jar` |

Conversations, choices, conditions, dialogue actions, cutscene orchestration and player progress belong to Interactions. Citizens supplies the NPC API and its native NPC systems. The Interactions JAR requires Citizens to be installed. Its Gradle task packages only the dialogue source-set output; Citizens archives contain no Interactions classes, resources or embedded JAR, and Interactions contains no Citizens classes.

Build both mods from the repository root with PowerShell 7 and JDK 21:

~~~powershell
./neoforge/gradlew.bat -p neoforge build --console=plain
~~~

Build the independent Interactions artifact with:

~~~powershell
./neoforge/gradlew.bat -p neoforge dialogueJar --console=plain
~~~

Outputs are in `neoforge/build/libs`. Release filenames follow the configured project version.
