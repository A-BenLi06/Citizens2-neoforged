# Failure-isolated server shutdown

Citizens now attempts each shutdown operation even when saving or a cleanup callback
throws. Editors and prompts close first, the default store is saved while providers are
still available, and every registered default, named, anonymous and temporary registry
is retired. Retirement releases runtime NPC ownership without deleting definitions,
including when despawn is vetoed. Registry bindings, sender selections, pending respawns,
death visuals, listener dispatchers, scheduler and API bindings are then released.
Provider cleanup follows trait disposal. Each failed operation is logged with its cause;
the exception is not thrown through the shared NeoForge stopping event, so later listeners
can still run. Repeated stopping notifications do not save or dispose twice.
The registry snapshot is captured before any callback, so a save callback removing a
named registry cannot make its NPCs escape retirement.

New registry creation and data operations are rejected during shutdown. The next server
start resets shutdown state and restores normal save-on-disable behavior. The selector
also drops anonymous-registry references rather than retaining them across sessions.
Only the default store participates in automatic shutdown saving; this does not introduce
automatic persistence for independently owned named/anonymous stores.

Editors and chat prompts retain a single dispatcher per server lifetime, unregister it
on shutdown, and reject new sessions before invoking callbacks. Bulk cleanup continues
after a callback failure and reports aggregated errors. Ordinary reload cleanup remains
available without permanently closing the session service. Shutdown callbacks cannot
reopen either service through registration.

The scheduler closes submissions, cancels active, incoming and asynchronous task handles,
and interrupts its async executor. A tick callback can shut down the scheduler without
invalidating an iterator or allowing subsequent queued callbacks to run. Nested scheduling
still waits for the next tick. Already running asynchronous code must cooperate with
interruption; shutdown cannot forcibly terminate arbitrary code.

The optional LuckPerms group bridge now releases API/reflection references and warning
state. It clears the active resolver only if that resolver belongs to this installation,
preserving a replacement provider. Old resolver objects cannot use a later installation.

## Validation

The [isolated native audit](../tools/shutdown-runtime-audit/README.md) requests a real
server stop and verifies cleanup in later stopping/stopped event listeners. It injects
simultaneous save, editor, prompt and trait-cleanup failures plus despawn vetoes. Both
NeoForge 21.1.233 and 21.1.248 pass 59 checks, including 19 session checks, all registry
kinds, task cancellation/rejection, selection/queue release and repeated-stop behavior.
The four intentional errors are reported; no fixture failure is expected.

Four scheduler unit tests cover handle cancellation, rejected submissions, in-callback
shutdown, next-tick scheduling and interruption. Running those tests against the original
`c441c11` scheduler produces three failures out of four. Two additional LuckPerms bridge
tests cover owned cleanup and replacement-provider preservation without requiring the
real provider. Native reload regression passes its existing 30 checks.

All 307 ordinary tests and 100 Interactions tests pass with zero failures, errors or
skips. The final default-version clean test/build succeeds and release archives exclude
audit classes. All 78 Interactions entry names and contents, including its versioned
manifest, match the preceding release; rebuilt ZIP container bytes differ. Citizens
contains no Interactions implementation/resources/embedded JAR and has no reverse mod
dependency. Interactions contains no Citizens classes. The original Citizens save retains
SHA-256 `cc99c930f8f5fbc49fe0c5eaf76002e1d19c45248304522b7ad1e83354dc1132`.

Evidence is recorded in `artifacts/shutdown-validation-summary.json`, generated by
`artifacts/verify-shutdown.ps1`. This does not establish full physical-client reconnect,
integrated-server restart, installed LuckPerms acceptance, or arbitrary third-party
cleanup behavior. Configuration/shop reload transactions remain separate work.

Interactions retains its independent NeoForge JAR and one-way dependency on Citizens.
No Interactions implementation or resources are moved into Citizens.
