## Install and rollback

Stop the server normally and prevent automatic restart while replacing files.
Back up the complete current server state, including mods, configuration,
worlds, player data and databases. If GriefLogger uses external MySQL, take a
matching database backup.

Remove old JARs with mod IDs `citizens`, `interactions`, `yuuniverse_economy`
and `grieflogger` from `mods/`, then install the four replacement runtime JARs.
Economy may previously have been named `economy.jar`; do not retain duplicates.
Preserve current configuration, NPC saves, dialogues, quests and financial data.
Keep the rest of the existing compatible provider pack. Required GriefLogger
dependencies include Architectury >=13.0.8 and SuperMartijn642's Config Lib
>=1.1.8. Economy requires NeoForge >=21.1.247; use the selected 21.1.248 target.

Start using the existing Java 21/NeoForge command. Review startup errors and
loaded versions. GriefLogger .10 migrates supported history schemas, so preserve
the pre-upgrade database backup. Synchronize updated hosted/client copies where
the existing pack includes them. Source JARs and source ZIPs stay outside `mods/`.

For rollback, stop the server and restore the complete matching pre-upgrade
snapshot and external database together. Restoring old JARs alone after a
schema migration is insufficient. Snapshot rollback discards later gameplay.
The older prepared Economy 0.5.0 upgrade package is separate and should not be
applied over these artifacts.

## Validation and limits

Citizens/Interactions were freshly assembled from `d0a7815`; every archive entry
matches the latest accepted ordinary build's contents. All four runtime JARs
match the adopted SHA-256 values. Packaging inspected descriptors, versions,
archive integrity and namespace separation. No new test suites or Minecraft
servers were started for this release.

Retained Citizens acceptance includes 847 ordinary tests on each of NeoForge
21.1.233 and 21.1.248, plus 244 navigation persistence checks. Historical provider
evidence is bounded to its recorded versions and scenarios. Physical-client
acceptance is deferred; remaining navigation scalar-default review and missing
original quest / ItemEdit content are documented in the repository. This is a
snapshot prerelease, not a claim that every function or migrated modpack workflow
has completed acceptance.
